# TheMathLib

TheMathLib é um portal simples que reúne duas aplicações matemáticas principais: **FoxTable** e **Metry**. O objetivo é oferecer um hub leve para acessar ferramentas de cálculo, tabelas e gráficos em uma interface limpa.

## Funcionalidades

- Navegação simples entre as páginas do projeto.
- Layout responsivo para telas menores.
- Integração com as aplicações `FoxTable` e `Metry` dentro da pasta `Webs`.
- HUD visual para exibir informações rápidas no site.

## Como usar

1. Abra o arquivo `index.html` em um navegador.
2. Use os botões para navegar entre as páginas e acessar as ferramentas.
3. Para abrir cada aplicativo em nova aba, utilize os links `Abrir FoxTable` ou `Abrir Metry`.

## Estrutura de pastas

- `index.html`
- `about.html`
- `maths.html`
- `styles.css`
- `Webs/FoxTable/index.html`
- `Webs/Metry/index.html`

## Nota

Este projeto foi criado como um hub educativo para experimentar e explorar pequenas ferramentas matemáticas online.
